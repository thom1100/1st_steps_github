# Cours

Dépose ici le contenu de tes cours, rangé par matière, par exemple :

```
cours/
  anatomie/
    rachis.pdf
    membre-inferieur.pdf
  physiologie/
  pathologie/
  techniques/        # massage, kinésithérapie respiratoire, etc.
  annales/           # anciens sujets de partiels (très utile à l'agent révision)
```

Formats acceptés : PDF (texte, pas scanné de préférence), .docx, .pptx, .md, .txt.
Nomme les fichiers clairement (`anatomie-rachis-cervical.pdf` plutôt que `cours3.pdf`).
